$$Z_0 = \text{characteristic impedance}$$
Characteristic impedance is a material property of the transmission line.
$$V(Z) = V_0^+e^{-j\beta Z} + V_0^-e^{j\beta Z}$$
$$I(Z) = I_0^+e^{-j\beta Z} + I_0^-e^{j\beta Z}$$
$$V_0^- = \left[\frac{Z_L - Z_0}{Z_L+Z_0}\right]V_0^+$$
$$\Gamma = \frac{V_0^-}{V_0^+} = \text{voltage reflection ratio}$$
$$\Gamma = \frac{Z_L-Z_0}{Z_L+Z_0}$$
$$Z_0 = \sqrt{\frac{R' + j\omega L'}{G' + j\omega C'}}\ \Omega$$
##### At $Z=0$
$$V(0) = V_0^+ + V_0^- = V_L$$
$$I(0) = \frac{V_0^+}{Z_0} - \frac{V_0^-}{Z_0} = I_L$$
$$Z_L = \frac{V_L}{I_L}$$
$Z_0, Z_L$ are generally complex, so $\Gamma$ has a phase and a magnitude.
$$\Gamma = |\Gamma|e^{j\theta_r} = |\Gamma|\angle \theta$$
$|\Gamma| \leq 1$

If $Z_L$ is matched, $Z_L = Z_0$ and there is no reflection ($\Gamma = 0$)
Open circuit: $Z_L = \infty, \Gamma = 1$
Short circuit: $Z_L = 0, \Gamma = -1$

#### 5.5 Standing Wave Ratio
What is the ratio between max and min voltage magnitude along the line?
$$s = \frac{\left|V(Z)\right|_{\text{max}}}{|V(Z)|_{\text{min}}} = VSWR$$
$$V(Z) = V_0^+e^{-j\beta Z} + V_0^-e^{j\beta Z}$$
$$V_0^- = \Gamma V_0^+$$
So...
$$V(Z) = V_0^+e^{-j\beta Z} + V_0^+\Gamma e^{j\beta Z} = V_0^+\left[e^{-j\beta Z} + |\Gamma|e^{j\theta_r} e^{j\beta Z} \right]$$
The magnitude of the voltage along the line is:
$$|V(Z)| = \sqrt{V(Z)V(Z)} = |V_0^+|\left\{ \left[e^{-j\beta Z} + |\Gamma|e^{j(\theta_r + \beta Z)}\right]\left[e^{j\beta Z} + |\Gamma|e^{-j(\theta_r + \beta Z)}\right]\right\}^{\frac{1}{2}}$$
$$ = |V_0^+|\left\{1 + |\Gamma|^2 + |\Gamma|\left[e^{j(2\beta + \theta_r)}+e^{-j(2\beta Z + \theta_r)}\right]\right\}^\frac{1}{2}$$
$$|V(Z)| = |V_0^+|\left[1 + |\Gamma|^2 + |\Gamma| \cos(2\beta Z + \theta_r)\right]^\frac{1}{2}$$
 
$|V(Z)|_{\text{max}}$ when $2BZ+\theta r = 2n \pi$ for $n=0,1,2,...$
$$|V(Z)|_{\text{max}} = |V_0^+|\left[1 + |\Gamma|^2 + 2|\Gamma|\right]^\frac{1}{2} = |V_0^+|\left\{\left[1 + |\Gamma|\right]\left[1 + |\Gamma|\right]\right\}^\frac{1}{2}$$
$$|V(Z)|_{\text{max}}= |V_0^+|(1 + |\Gamma|)$$
$|V(Z)|_{\text{min}}$ when $2BZ + \theta r = (1 + 2n)\pi$ for $n = 0,1,2, ...$
$$|V(Z)|_{\text{min}} = |V_0^+|(1 - |\Gamma|)$$
So $VSWR$ is 
$$\text{VSWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$
